# StudySmart-Canada-Live-Dashboard
Live Power BI analytics dashboard integrating Python, OpenWeather API, and student affordability analysis across Canadian cities.

## Project Overview
StudySmart Canada is a live Power BI dashboard that helps compare Canadian cities for international students based on:
- Monthly living cost
- Safety
- Average wage
- Live weather conditions

The project uses Python and OpenWeather API to update weather data automatically.

---

## Features
- Live weather data integration
- Interactive Power BI dashboard
- Student Survival Score analysis
- Cost and affordability comparison
- Maps, KPI cards, and charts
- Executive insights and recommendations

---

## Technologies Used
- Power BI
- Python
- Pandas
- OpenWeather API
